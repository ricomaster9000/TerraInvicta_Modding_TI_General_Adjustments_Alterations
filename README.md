# Terra Invicta Augmenter

A general "balancing" mod for [Terra Invicta](https://store.steampowered.com/app/1176470/Terra_Invicta/) that adds a few minor features and alterations. Everything is modular — each feature can be toggled and tuned from a config file — and it is save-game compatible and designed to play nicely with other mods.

- **Nexus Mods:** https://www.nexusmods.com/terrainvicta/mods/14
- **Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=2878051407
- **Version:** 0.3.5 · **Author:** ModMaster9000 · **License:** MIT

## Features

### Additions

- **Resource depletion** — hab site resources are now finite. Each site gets a total pool sized to guarantee a sensible minimum lifetime for its body type (planets last decades, asteroids/comets a few years), with a bonus for large bodies that have few sites. When a pool runs out the site shows `EMPTY`, its output drops sharply ("recycling mode") and a notification is raised.
- **Follow-up failure modifier** — a councilor who fails a mission has a lower chance of success the next time they try the *same mission at the same location*. Stacks up to 5 × 10% (≈ −50%), resets 56 days after the last failure. Shown as a modifier when selecting the mission.
- **Follow-up success modifier** — same idea for repeated successes, capped at 3 × 5% (≈ −15%).
- **Protect mission boost** — Protect missions gain an Operations slider; the modifier applied to opposing missions at that location is `ops spent × 0.33`.
- **Dynamic councilor recruit cost** — Influence cost to hire a councilor scales with their attribute totals.
- **Abandon Nation purges control points** — when the human player abandons a nation with auto-renew on, all their control points there are actually removed at the next mission phase (AI excluded).

### Adjustments (all configurable)

- Nuclear barrages do ~100% more GDP damage and ~100% more population damage to the target nation; global GDP fallout multipliers are also exposed.
- Mission Control generated by habs increased ×4 (works with hab modules added by other mods).
- Recruitable councilors can roll higher starting attributes (global multiplier plus per-attribute overrides).
- Councilor recruit pool increased from 8 to 12.

## Requirements

- [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) 0.32.4a or newer, installed on Terra Invicta with the **DoorstopProxy** method.

## Installation

1. Install Unity Mod Manager and point it at your Terra Invicta game directory.
2. Download `TI_Augmenter.zip` from the Nexus files page (or from this repo).
3. In UMM's *Mods* tab, click *Install mod* and pick the zip.
4. Launch the game. **The first launch (and the first launch after any game update) will automatically restart the game once** — the mod runs an "extended installer" that exposes a few members of the game's `Assembly-CSharp.dll` that the patches need. This is expected.
5. When the main menu loads you should see the grey UMM window with a green dot next to *Terra Invicta Augmenter*. If you don't, restart the game once more.

If your antivirus quarantines `EXTENDED_INSTALL.bat` or `ExtendedInstaller.exe`, add an exception and restore them.

## Configuration

Edit `TI_Augmenter/TI_Augmenter_Config.txt` in the mod folder (`key=value`, one per line):

| Key | Default | Effect |
|---|---|---|
| `nuclear_barrage_related_configurations_enabled` | `true` | Master switch for nuke multipliers |
| `nuclear_GDP_damage_to_target_nation_multiplier` | `2.00` | Target nation GDP damage |
| `nuclear_population_damage_to_target_nation_multiplier` | `2.00` | Target nation population damage |
| `nuclear_GDP_damage_global_multiplier` | `1.50` | Global GDP hit from large strikes |
| `nuclear_GDP_damage_global_because_of_core_region_multiplier` | `1.50` | Global GDP hit when a core region is destroyed |
| `agent_follow_up_success_failure_modifiers_enabled` | `true` | Master switch for follow-up modifiers |
| `agent_follow_up_failures_decrease_chances_of_success_max_count` | `5` | Max stacked failures |
| `agent_follow_up_failures_decrease_chances_of_success_factor` | `0.10` | Penalty per failure |
| `agent_follow_up_successes_decrease_chances_of_success_max_count` | `3` | Max stacked successes |
| `agent_follow_up_successes_decrease_chances_of_success_factor` | `0.05` | Penalty per success |
| `faction_related_configurations_enabled` | `true` | Master switch for faction tweaks |
| `faction_hab_mission_point_generation_multiplier` | `4.0` | Hab Mission Control multiplier |
| `mission_related_slider_additions_enabled` | `true` | Ops slider on Protect missions |
| `mission_related_slider_operations_boost_modifier` | `0.33` | Modifier per Ops spent |
| `agent_attributes_alterations_enabled` | `true` | Master switch for councilor stat/cost changes |
| `agent_attributes_all_range_recruit_pool_modifier` | `3.0` | Multiplier on the random attribute range |
| `agent_attributes_<attribute>_range_recruit_pool_modifier` | e.g. `investigation=1.5`, `loyalty=0.5` | Per-attribute multiplier stacked on the above |
| `agent_attributes_cost_factor_multiplier` | `2.0` | Influence cost per attribute point |
| `resource_depletion_enabled` | `true` | Finite hab site resources |
| `remove_control_point_permanently_on_abandon_nation` | `true` | Purge control points on Abandon Nation |
| `enable_debug_mode` | `false` | Verbose `TI_Augmenter:` logging |

Resource depletion state is stored next to each save as `<savename>_resource_pool_data.txt`; delete it to regenerate totals for that save.

## Building from source

- .NET Framework 4.8 class library, C# 10, old-style `.csproj`. Open `TI_Augmenter.sln` in Rider/Visual Studio, or build from the command line with any .NET Framework MSBuild:

  ```bash
  MSBuild.exe TI_Augmenter.csproj -p:Configuration=Debug
  ```

- Game and loader assemblies are referenced from `import/` (copies of `TerraInvicta_Data/Managed/*.dll`, `0Harmony.dll`, `UnityModManager.dll`). After a game update, replace `import/Assembly-CSharp.dll` and rebuild.
- Output lands in `bin/Debug/TI_Augmenter.dll`; copy it (and the `.pdb`) into `TI_Augmenter/` and zip that folder to produce a release.
